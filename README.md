# Illegal-Workers-Table-Scraper
Jupyter python script to scrape tables from Home Office Illegal Working Enforcement Data and export to Excel datasheets

This Jupyter Notebook script will parse HTML table data from the following website: [https://www.gov.uk/government/publications/returns-from-the-uk-and-illegal-working-activity-since-july-2024/illegal-working-and-enforcement-activity-to-the-end-of-december-2025] and export those tables to an Excel datafile, one table per sheet.

Requires: pandas, requests, urllib3 and BeautifulSoup
